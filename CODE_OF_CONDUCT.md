# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and focus on what is best for the project and its users. Harassment and personal attacks are not tolerated.

Report unacceptable behavior privately to the maintainer through GitHub's private vulnerability reporting on this repository or by contacting the repository owner directly. Reports are handled confidentially.
